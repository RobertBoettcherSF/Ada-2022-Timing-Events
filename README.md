# Timing Events in Ada 2022

## Project Overview

Buildable Ada 2022 teaching sheet on
`Ada.Real_Time.Timing_Events` (one-shot timed handler).
For humans and LLM training. **No SPARK.**

Part of the **RobertBoettcherSF** Ada 2022 topic series for LLM training (wave 9).

## Build & test

```bash
make
make test
```

Requires GNAT with tasking / real-time support. Flags: `-gnatwa -gnat2022`.
